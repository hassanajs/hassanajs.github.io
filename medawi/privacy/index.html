سياسة الخصوصية

توضح هذه السياسة كيفية تعامل تطبيق مداوي، الذي تديره Neuron Agency، مع بيانات الأطباء والعيادات والمرضى.

تاريخ السريان وآخر تحديث: 26 آب 2026

خصوصيتك مسؤولية نأخذها بجدية

مداوي نظام لإدارة العيادات مخصص للأطباء والمستخدمين المخولين. نعالج البيانات فقط لتشغيل وظائف الخدمة وحماية الحساب وتقديم الدعم، ولا نبيع البيانات الشخصية أو الطبية ولا نستخدمها للإعلانات أو التتبع الإعلاني.

1. البيانات التي نعالجها

  • بيانات الطبيب والعيادة: الاسم ورقم الهاتف والاختصاص والجنس وتاريخ الميلاد والعنوان والبريد الإلكتروني وبيانات العيادة وصور الهوية المهنية.
  • بيانات المرضى والسجلات الصحية: بيانات التواصل والتاريخ الطبي والجراحي والدوائي والتشخيصات والملاحظات والأعراض والوصفات والتعليمات والفحوص والصور والمرفقات والإحالات.
  • بيانات العمل والماليات: المواعيد والجلسات والخدمات والفواتير والمدفوعات والتقارير.
  • المحتوى الصوتي: التسجيلات التي يختار الطبيب إرسالها لاستخدام ميزات المعالجة الصوتية والذكاء الاصطناعي.
  • بيانات الجهاز والحساب: رمز Firebase الخاص بالإشعارات، حالة قراءة الإشعارات ورمز تسجيل الدخول اللازم لحماية الجلسة.

2. أغراض استخدام البيانات

نستخدم البيانات لتشغيل حساب الطبيب وإدارة العيادة والمرضى والمواعيد والجلسات والسجلات المالية، وإنشاء الملفات والتقارير وملفات PDF، وإرسال الإشعارات المتعلقة بالحساب والاشتراك، وتقديم الدعم وحماية الخدمة ومنع إساءة الاستخدام.

تُستخدم التسجيلات الصوتية فقط عندما يبدأ الطبيب ميزة التحويل أو الاستخراج الصوتي. لا يبدأ التطبيق التسجيل أو الإرسال من تلقاء نفسه.

3. مقدمو الخدمة والمشاركة

قد تُعالج البيانات لدى مزودي البنية التحتية والاستضافة الضروريين لتشغيل الخدمة، ولدى Firebase لإيصال الإشعارات، ولدى مزودي معالجة الذكاء الاصطناعي عند استخدام الميزات الصوتية. يُقصر الوصول على ما يلزم لتقديم الوظيفة المطلوبة.

لا نكشف البيانات لأطراف أخرى إلا لتقديم الخدمة، تنفيذاً لطلب المستخدم، أو عند وجود التزام قانوني صحيح. ونتوقع من مقدمي الخدمة حماية البيانات وفق التزامات مناسبة لطبيعتها.

4. الأذونات واختيارات المستخدم

يُطلب إذن الميكروفون عند استخدام التسجيل الصوتي، ويختار الطبيب الملفات والصور التي يريد رفعها بنفسه. يمكن رفض إذن الإشعارات أو تعطيله من إعدادات الجهاز دون منع الوصول إلى السجلات داخل التطبيق.

يتحمل الطبيب أو المستخدم المخول مسؤولية إدخال بيانات المرضى عندما يملك الصلاحية والأساس المهني أو القانوني المناسب لمعالجتها.

5. أمن البيانات

تُنقل البيانات عبر اتصالات مشفرة، ويستخدم التطبيق مصادقة للحساب وضوابط وصول تربط سجلات العيادة بالطبيب المخول. نطبق تدابير تقنية وتنظيمية معقولة، مع الإقرار بأنه لا توجد وسيلة إلكترونية تضمن حماية مطلقة بنسبة 100%.

6. الاحتفاظ بالبيانات

نحتفظ بالبيانات طوال مدة الحساب وبالقدر اللازم لتقديم الخدمة والوفاء بالالتزامات القانونية والمهنية وحل النزاعات. قد تتطلب السجلات الطبية أو المالية فترات احتفاظ يحددها القانون أو الجهة المهنية المختصة.

7. حذف الحساب والبيانات

يمكنك بدء طلب حذف حسابك والبيانات المرتبطة به عبر البريد. اذكر اسم المستخدم أو رقم الهاتف المسجل حتى نتمكن من التحقق من ملكية الحساب. سنوضح قبل الإكمال أي بيانات يجب الاحتفاظ بها لالتزام قانوني أو مهني.

8. بيانات القاصرين

مداوي مخصص للأطباء ومستخدمي العيادات المخولين، وليس موجهاً للقاصرين لإنشاء حسابات. قد تتضمن ملفات المرضى بيانات قاصرين يدخلها مختص صحي مخول ضمن تقديم الرعاية.

9. تحديث السياسة

قد نحدّث هذه السياسة عند تغير الخدمة أو المتطلبات القانونية. سنحدث التاريخ المبين أعلى الصفحة، وقد نرسل إشعاراً داخل التطبيق عندما يكون التغيير مهماً.
